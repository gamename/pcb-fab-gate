# pcb-fab-gate

Reusable KiCad PCB fabrication gate for every SVW / GNI / Helios board repo,
regardless of GitHub org. See [SVW-0036](https://github.com/svw-platform/svw-governance/blob/main/briefs/2026-07-26-SVW0036-pcb-fab-gate-all-boards.md)
for the full design and rollout.

Full documentation lands with the initial feature PR.
